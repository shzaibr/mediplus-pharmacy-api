SERVICE RETENTION REASONS

accounts-daemon.service: Retained to provide user-account information to graphical login and desktop components.
cron.service: Retained to execute scheduled maintenance and administrative tasks.
dbus.service: Retained because desktop and system components depend on inter-process communication.
fail2ban.service: Retained to protect SSH against repeated failed login attempts.
getty@tty1.service: Retained to provide local console login and recovery access.
irqbalance.service: Retained to distribute hardware interrupts across available CPU cores.
lightdm.service: Retained because the XFCE graphical desktop is required for university project work.
mediplus.service: Retained to run the MediPlus Pharmacy API through systemd.
networkd-dispatcher.service: Retained to handle scripts associated with network interface state changes.
NetworkManager.service: Retained to provide network-device management for desktop and optional network interfaces.
nginx.service: Retained as the HTTP reverse proxy listening on port 80 and forwarding requests to Gunicorn.
open-vm-tools.service: Retained to provide integration between the Ubuntu guest and VMware host.
polkit.service: Retained to authorize privileged operations requested by desktop and system applications.
postgresql@14-main.service: Retained because the local permission_rag database belongs to the separate RAG project; PostgreSQL listens on localhost only.
rsyslog.service: Retained to collect and manage system and application logs.
rtkit-daemon.service: Retained to provide real-time scheduling support for desktop audio applications.
snapd.service: Retained because LXD is installed as a Snap application and Snap manages Snap applications and their updates.
ssh.service: Retained to provide secure remote administration using SSH public-key authentication.
systemd-journald.service: Retained to collect and store system and kernel logs.
systemd-logind.service: Retained to manage user logins, sessions and system seats.
systemd-networkd.service: Retained as part of the VM's network configuration.
systemd-resolved.service: Retained to provide DNS name resolution.
systemd-timesyncd.service: Retained to synchronize the system clock with network time servers.
systemd-udevd.service: Retained to detect devices and manage device nodes and permissions.
udisks2.service: Retained to support disk management and storage operations in XFCE.
unattended-upgrades.service: Retained to install available security updates automatically.
upower.service: Retained to provide power and device-status information to desktop components.
user@1000.service: Retained to manage background processes and services for the logged-in user.
vgauth.service: Retained to provide VMware guest authentication integration.
